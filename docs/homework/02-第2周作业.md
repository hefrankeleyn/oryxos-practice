**第二题答案（已完成 PR 提交，2026-10-27）**

在第一题的实践中发现：飞书通知渠道表单无法填写签名密钥，编辑保存时还可能丢失此前通过 API 配置的密钥。

已在 `fix/feishu-notify-signing-secret` 分支增加飞书签名密码输入框，并按确认的规则调整编辑行为：不改密钥框则保留，主动清空则删除，填写新值则替换；API 没有传 `secret` 字段时仍保留。切换渠道类型时不自动继承旧凭证。
