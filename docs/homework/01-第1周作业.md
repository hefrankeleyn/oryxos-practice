# 第 1 周作业

## 第 1 题

### 题目

1. **必做：**第一周的核心内容是 AI 编程总论。讲下看完后你对 AI 编程的认知的变化（是否有变化，有哪些变化）。思考一下这些内容如何在你以后的工作中用起来。

> 我认为只要是内容肯定或多或少有收获，有也好，没有也好，关键是你看完后，对 AI 编程的判断是什么，对内容的判断是什么。现在内容太多了，核心是我希望你慢慢养成看到内容后，有自己的判断，会思考对自己有没有用。
>
> 这点是写给你自己看的，不要用交作业的角度去思考。

### 答案

在没有读AI编程的认知之前，我有很深的焦虑感，我觉得AI完全可以代替我，我可能要在IT行业中失业了。读完AI编程的总论之后，我对AI已经有了比较清晰的认识，确实达到了对AI的祛魅。

AI对程序员这个职业冲击最大的是工作流，在AI介入之前，很多的程序员只负责某一个很具体的业务模块开发。AI介入之后，带动了整个工作流的变革。工作流本身没变，变的是，AI让整个工作流变得更加高效。

首次是AI本身，我非常认同七个层次：LLM、工具、配置约束、协作机制、协议生态、工作流、方法论。我理解配置约束就是SDD+Herness、协作机制是大模型厂商提供的功能（worktree、plan mode、subagents）、协议生态是与外部协作的方式。

对程序员的要求，AI要求我们不要再去仅仅当一个螺丝钉了，提示我们不要偷懒，因为可以偷懒的工作，AI全部可以做了。提醒我们要真的去成功一个工程师，甚至成为一个老板。

对软件开发流程的影响，需求、架构、开发、测试、部署、运维。每一个环节AI都介入进来，但是每一个环节都要人的判断放到一个很重要的位置。所以AI来到来，对我们技术专业能力的要求更加高了。因为我们没有理由再去偷懒了。

## 第 5 题

### 题目

5. **必做：**当你初步了解 OryxOS，思考当你学完这个项目后，你准备从里面学到什么：Agent 的开发？Agent OS 的开发？一个开源 Agent OS 的从 0 到 1？想把它推成一个不错的开源项目？给自己的简历增加重量？

> 我其实收到好几个反馈，OryxOS 这个项目里面做到的东西，业界有很多非常匹配的岗位。所以我希望你去思考这个问题，如果你对转型 AI Agent 开发有想法，这个问题就是你的起点。

### 答案

当我了解了 OryxOS 之后，我期待从中学到：

1. **Agent 的开发：**在 AI 迅速发展的过程中，我深刻地体会到，对于程序员来说，重要的不再只是动手实现代码的能力，而是做判断和决策的能力。很多事情总结成工作流之后，都可以让 Agent 进行实现，从而把程序员从中解放出来。
2. **Agent OS 的开发：**随着 AI 持续发展，我非常认同，对于普通程序员来说，现在能够参与的领域中，Agent OS 必然是一个重要领域。未来需要调用多个 Agent 协同工作，Agent OS 不可或缺。所以我非常期待学习 Agent OS 的开发。
3. **一个开源 Agent OS 从 0 到 1 的过程：**在这个过程中，我期待为自己的简历增加重量，并学习大型开源项目的实践过程。
